Character importer

Turns character-creator exports into game art. Everything happens in this page; nothing is uploaded anywhere.

1 · Drop the exports

Drop the SVG files hereor click to choose them. One file per expression, same pose and canvas.

2 · Check it

At true scale next to Ellie (165 cm). Heights come straight from the creator, so this is how they'll stand in the game.

3 · Put it in the game

  1. On GitHub, open the repository's art/chars folder (on the branch you play from).
  2. Add file → Upload files, drop the downloaded file in, and commit. Replacing an existing file is fine.
  3. Reload the game. No rebuild needed.

Playing from a copy on your computer instead? Put the file in that copy's art/chars folder.
